# Balanço de Natal do Estoque

Página estática (um `index.html`, sem build) com o resumo da comparação de estoque Fluxo × TOTVS de 17/11/2026: 99,6% integrado, com neve que segue o cursor, gráficos interativos e trilha de Natal.

- A trilha é sintetizada no navegador (Web Audio) a partir de melodias em domínio público: *Jingle Bells* (J. L. Pierpont, 1857), *We Wish You a Merry Christmas* e *Deck the Halls* (tradicionais). Nenhuma gravação é usada.
- O botão "Baixar PDF" baixa o resumo de 1 página (`estoque-integrado-resumo-17-11-2026.pdf`).
- Publicada na Vercel como site estático: o `index.html` da raiz é a página.
